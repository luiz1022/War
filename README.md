# War
Projeto desenvolvido em C para simular o cadastro de territórios de um jogo de estratégia. A aplicação utiliza estruturas de dados (`struct`), vetores, funções e manipulação de strings para armazenar e exibir informações sobre territórios, exércitos e tropas. O objetivo foi aplicar conceitos fundamentais de programação, organização de dados e boas práticas de desenvolvimento em linguagem C.
